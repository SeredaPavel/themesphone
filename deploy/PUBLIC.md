# Публикация ThemesPhone: ограничения и возврат функций

## Исходное состояние

Проверенная версия до публикации: `67b53eeb1cdef61cd29fae0e0e13bbad6593fb37`.
Отметка Git: `before-public-access-20261022` — создать на этом коммите и отправить
в origin перед слиянием изменений публикации. Тег сохраняет код, не базу данных.

Интерфейс, формы авторизации, корзина, кнопки покупки/скачивания и обработчики
сохранены. Ничего не вырезано. Каталог, фильтры, страницы и панель Strapi доступны.
Часть видимых действий пока не завершается из-за ограничений API ниже.
Это сайт в разработке, не готовый магазин.

## Изменения приложения

- Next.js 15.3.3 → 15.5.28 и соответствующий package-lock.json.
  Официальное обновление безопасности от 14 октября 2026:
  https://nextjs.org/blog/nextjs-security-update-october-14-2026
- `frontend/src/lib/api.ts`: браузер использует NEXT_PUBLIC_STRAPI_URL,
  сервер — STRAPI_API_URL. Фильтрам не требуется backend на компьютере посетителя.
- Dockerfile frontend: метка public-proxy-ready для проверки версии перед публикацией.

Остальные изменения относятся к скриптам развёртывания, workflow и документации.
Страницы, компоненты, формы и API-обработчики приложения не изменены.
Локальный Compose не включает публичный Caddy: локально прежний код доступен
для дальнейшей доработки без этих ограничений.

## Временные ограничения на публичных доменах

Источник правил: `deploy/themesphone-public.caddy`. Рабочая копия после публикации:
`/opt/hosting/edge/conf/Caddyfile`. Push приложения её автоматически не заменяет.

| Адрес | Текущее поведение | Что требуется перед разрешением |
| --- | --- | --- |
| Четыре имени сайта: страницы и Next images | Доступны, интерфейс прежний | Обычная проверка изменений |
| Сайт: GET/HEAD `/api/top-wallpapers` | Разрешены | Только публичные данные |
| Сайт: остальные `/api` и `/api/*` | HTTP 410, JSON о временной недоступности | Открывать конкретные маршруты после проверки |
| Сайт: `/api/download` | HTTP 410 | Убрать произвольный URL; проверять источник/ID файла, размер, права и покупку; закрыть SSRF |
| Сайт: `/api/checkout/start`, `/api/checkout/pay` | HTTP 410 | Серверные цены, владелец заказа, настоящий платёжный провайдер, подпись webhook и повторные уведомления |
| Сайт: API входа, регистрации, OAuth, подтверждения, `/api/me` | HTTP 410; формы остаются | Проверить полный цикл, cookies, OAuth redirect/state, права; убрать логирование токенов |
| CMS: GET/HEAD wallpapers/categories/devices и отдельных записей | Проксируются с обычными правами Strapi | Проверить публичные поля и populate; не раскрывать приватные связи |
| CMS: остальные `/api`, включая users/orders/auth и запись в коллекции | HTTP 410 | Роли, владельцы, права, валидация; разрешать адресно |
| CMS: `/documentation` | HTTP 404 | Открывать только при необходимости и с подходящим доступом |
| CMS: админка и служебные маршруты | Проксируются, штатная авторизация Strapi | Панель публично достижима; надёжный пароль администратора, не расширять публичные права |
| CMS: `/uploads/*` | Доступны напрямую | Запрет API скачивания не защищает платные изображения |

Это не полный аудит безопасности. Права Strapi, обновления остальных зависимостей,
законченная авторизация, платежи и защита платных файлов остаются задачами проекта.

## Как вернуть функцию

1. Доработать и проверить её локально. Исходники уже находятся в прежних файлах.
2. Отправить изменения в main: Actions соберёт образы и обновит приложение на VPS.
3. В `deploy/themesphone-public.caddy` добавить точное разрешение метода/пути
   ПЕРЕД общим запретом `/api`. При необходимости отдельно разрешить адрес CMS.
   Не удалять общий запрет ради одной функции.
4. Прочитать и сохранить актуальный общий Caddyfile, перенести нужное правило
   только в блок ThemesPhone, выполнить Caddy validate и reload. Проверить функцию,
   запрет остальных API, GeoConverter и ProfitSite.
5. Обновить эту таблицу и HTTPS-проверки скриптов для разрешённого маршрута.

`publish-public.sh` выполняет однократный переход с заглушки. Повторно для изменения
правил его не запускать. Next.js откатывать ради включения функции не нужно:
доступ ограничен в Caddy, исходники обработчиков сохранены.

## Как найти исходную версию

```powershell
git show before-public-access-20261022:frontend/src/components/Header.tsx
git diff before-public-access-20261022 -- frontend/
git worktree add --detach ..\themesphone-before-public before-public-access-20261022
```

Последняя команда создаёт отдельную папку для изучения кода без изменения рабочей
ветки. Не копировать туда секреты без необходимости. Не разворачивать старый тег
публично: он содержит прежнюю версию Next.js. Откат кода не восстанавливает базу.

## Переход и резервные копии

Сначала установить обновлённый deploy-скрипт на VPS с резервной копией прежнего,
затем развернуть прошедшую Actions версию в preview и проверить её.
`publish-public.sh` сохраняет общий Caddyfile и режим в
`/opt/hosting/backups/themesphone-public-<дата>-<суффикс>/`, валидирует кандидат,
заменяет только заглушку ThemesPhone, включает `access-mode=public`, проверяет
HTTPS и оба соседних сайта. Затем отключает preview и повторяет проверки.
При ошибке пытается вернуть заглушку, прежний режим и preview; ошибки самого
восстановления требуют внимания. Настоящую аварию на VPS пока не имитировали.

После успеха удалить только отмеченный блок ThemesPhone SSH preview из Windows
hosts, предварительно сохранив файл; выполнить `ipconfig /flushdns`, закрыть туннель.
Проверить домены без туннеля, в том числе с другого устройства.

Дальнейшие push main обновляют приложение автоматически без preview.
База и uploads остаются в постоянных каталогах. Снимки перед обновлениями
находятся в `/opt/hosting/backups/themesphone/releases/`; внешние резервные копии
и политика хранения ещё не настроены.
